# || Planificador de tareas 📋

Pagina web diseñada para porder organizar nuestras tareas y responsabilidades por orden de prioridad, se ingresa desde un formulario que se muestra una vez el usuario presiona el boton de añadir tarea, el usuario agrega la informacion solicitada y se organiza dicha tarea en una lista con fecha de entrega, se le dara al usuario la posibilidad de marcarla como completada o la podra marcar como cancelada y borrarla
